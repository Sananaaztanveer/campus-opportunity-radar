Campus Opportunity Radar

A web app for students to collect and organize campus events,
hackathons, coding contests, and workshops.

Features
- Add opportunities with a date, eligibility, and link
- Filter opportunities by type
- Save opportunities and mark applications
- Keep entries in the browser after refreshing

Built with HTML, CSS, JavaScript, and browser local storage.

How to use
Open index.html in a web browser.
